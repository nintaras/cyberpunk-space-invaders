# Cyberpunk Space Invaders 👾🚀

A retro 2D arcade space shooter game built with **Python** and **Pygame**[span_0](start_span)[span_0](end_span).

## 🎮 Features
- **Procedural Sprites:** Retro cyberpunk-styled player, enemy, and laser graphics drawn purely with code[span_1](start_span)[span_1](end_span).
- **Score Tracking:** Real-time on-screen score display[span_2](start_span)[span_2](end_span).
- **Dynamic Difficulty:** Enemy speed increases progressively as your score climbs[span_3](start_span)[span_3](end_span).

## 🕹️ Controls
- **Left Arrow:** Move left[span_4](start_span)[span_4](end_span)
- **Right Arrow:** Move right[span_5](start_span)[span_5](end_span)
- **Spacebar:** Fire laser[span_6](start_span)[span_6](end_span)
